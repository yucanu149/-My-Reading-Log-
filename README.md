# 私の読書記録（My Reading Log）

読書を「知識のインプット」で終わらせず、**多角的な思考**と**具体的な行動定着**につなげるための個人専用Webアプリケーションです。  
バックエンドサーバーや外部データベース、APIキーは一切不要で、すべてお使いのブラウザ単体（`localStorage`）で完結・自動保存されます。

---

## 主な特徴・コンセプト

1. **サーバー不要・ブラウザ完結**
   - すべての読書データやアップロードした表紙写真は、ブラウザ内の `localStorage` に自動保存されます。
   - インターネット接続がないオフライン環境でも、すべての項目を快適に入力・閲覧・編集できます。
2. **「読む前」から「読んだ後の行動」までを一貫サポート**
   - 単なる感想メモではなく、「なぜ読むのか（問い）」「複数の引用と考察」「本全体の総合レビュー」「あえて反論・批判的に問い直す視点」「明日からどう行動を変えるか」「実践後の振り返り」までを体系的に記録できます。
3. **落ち着いた読書ノート風デザイン**
   - Stone / Slate 系のオフホワイトと明朝体（Noto Serif JP）を組み合わせた、目が疲れにくく知的なタイポグラフィ設計。PC・タブレット・スマートフォンのすべてに完全レスポンシブ対応しています。

## 機能一覧

### 1. ホーム画面（一覧・ダッシュボード）
- **本日のハイライト（デイリー復習カード）**
  - 過去に記録した複数の「好きな文章（引用）」と「その文章へのメモ・考え」の中から、ランダムに1つをトップに抽出表示します。
  - **「別のフレーズを見る」** ボタンでいつでも再抽選でき、**「この読書ノートを開く」** から該当書籍の詳細へすぐ移動できます。
- **キーワード検索・フィルターバー**
  - **キーワード検索**: タイトル・著者名・要約・好きな文章・全体の感想・本質の一言・タグを横断してリアルタイム検索できます。
  - **ステータス絞り込み**: 「すべて」「読みたい」「読書中」「読了」の4タブで絞り込み（各ステータスの冊数バッジ付き）。
  - **カテゴリ / タグ絞り込み**: 登録されているタグ（`#思考法`、`#ビジネス`、`#習慣化`、`#小説` など）をワンクリックでフィルタリングできます。
- **書籍カード一覧**
  - 表紙画像（未設定時はタイトルと著者が印字された装丁風プレースホルダー）、読書ステータス、記録日、引用件数バッジ、タグ、要約プレビュー、本質の一言／行動プランを表示します。

---

### 2. 読書記録の入力・編集フォーム
ヘッダーの **「+ 新しい本を記録する」** ボタン、または詳細画面の **「編集」** ボタンから開きます。

| セクション | 記録項目 | 内容・特徴 |
| :--- | :--- | :--- |
| **① 本の情報** | 表紙写真・タイトル（必須）・著者名・出版日・ページ数・読んだ日・ステータス・タグ | **表紙写真のアップロード**に対応（クリック選択・ドラッグ＆ドロップ・スマホのカメラ撮影やアルバム選択）。画像は自動で軽量な Base64 形式に変換され、その場でプレビュー・変更・削除が可能です。タグはカンマ区切り入力のほか、プリセットタグのクリック選択にも対応しています。 |
| **② 読む前の問い** | テキストエリア | なぜこの本を読もうと思ったのか、現在抱えている課題や持ち帰りたいヒントを記録します。 |
| **③ 本の要約** | テキストエリア（文字数カウント付き） | どんなテーマの本なのか、自分の言葉で1〜2行（100〜140文字目安）に凝縮してまとめます。 |
| **④ 好きな文章と自分の考え** | **複数追加可能なリスト形式**<br>（該当ページ / 好きな文章 / この文章へのメモ・考え） | 心に刺さったフレーズとそれに対する考察を1セットとして、**「+ 好きな文章・メモを追加する」** ボタンで何個でも追加できます（2個以上ある場合はセット単位で削除可能）。 |
| **⑤ 本全体の感想・総合レビュー** | テキストエリア | 個別の引用とは別に、本を一冊読み通して感じた総合的な感想・意見・総括を長文で自由に記録します。 |
| **⑥ 筆者への反論・批判的視点** | テキストエリア | 著者の主張を鵜呑みにせず、「本当にそうか？」「例外や前提条件はないか？」と多角的に問い直したメモを残します。 |
| **⑦ どう行動を変えるか** | テキストエリア | 「いつ、どこで、何をするか」という具体的なアクションプランを設定します。 |
| **⑧ 行動の振り返り・進捗** | テキストエリア | ⑦の行動プランを実際に試してみた結果や、自分に起きた変化を記録します。 |
| **【任意】本質の一言** | アコーディオン式1行入力（文字数カウント付き） | 本を閉じたあとも心に残したい「核となるメッセージ」を20〜30文字程度で一言にまとめます。 |

---

### 3. 詳細画面（Reading Notebook）
書籍カードをクリックすると、本棚からノートを取り出して開くような詳細モーダルが表示されます。
- **複数引用と考察のカード表示**: 登録したすべての「好きな文章（太字明朝体・ページ番号バッジ付き）」と「その文章へのメモ・考え」がセットで縦に美しく並びます。
- **本全体の感想ブロック**: 総合レビューが見出し付きの大きなブロックで表示されます。
- **ステータスのワンクリック切り替え**: 詳細画面上部から「読みたい」「読書中」「読了」をその場で即座に切り替えられます。
- **行動の振り返りのクイック追記**: 詳細画面の「⑧ 行動の振り返り・進捗」にある **「進捗を追記する」** リンクから、フォーム全体を開かなくてもその場で実践結果を追記・保存できます。
- **編集・削除機能**: 誤操作を防ぐ2段階確認付きの削除ボタンと編集ボタンを備えています。

## 使い方・起動方法

### 方法A：そのままブラウザで開いて使う（推奨・インストール不要）
Node.js などの開発環境がなくても、フォルダ内の **`index.html`** をダブルクリックしてブラウザ（Google Chrome / Microsoft Edge / Safari 等）で開くだけで、すべての機能をすぐに利用できます。

1. `index.html` をブラウザで開きます。
2. 初回起動時は、使い方のイメージが掴みやすいよう4冊分のサンプル読書記録（『思考の整理学』『複利で伸びる1つの習慣』『ファスト＆スロー』『星を継ぐもの』）があらかじめ登録された状態で表示されます。
3. サンプルデータは自由に編集・削除して構いません（すべて削除した場合でも、画面上の「サンプル読書記録を復元する」ボタンからいつでも初期状態に戻せます）。

### 方法B：Vite + React 開発サーバーで動かす場合
Node.js 環境がある場合は、以下のコマンドでローカル開発サーバーやビルドを実行できます。

```bash
# パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# 本番用ビルドの生成
npm run build
```

## データの保存と注意点

- **保存先**: ブラウザの `localStorage`（キー名: `my_reading_log_books_v1`）に自動保存されます。
- **画像の軽量化**: アップロードした表紙写真は自動で適切なサイズ（最大幅600px・JPEG圧縮）に最適化されてから Base64 形式で保存されるため、スマートフォンの高解像度写真でもブラウザの保存容量上限を圧迫しにくい設計になっています。
- **ブラウザデータの消去について**: 同じPC・スマートフォンの同じブラウザで開く限りデータは永続的に保持されますが、「ブラウザの閲覧履歴・サイトデータの消去」を行うと `localStorage` の内容も消去されるためご注意ください。
